# 🍕 Pizzaria do Manoel

## 📌 Sobre o projeto

O **Pizzaria do Manoel** é um projeto de sistema de gerenciamento desenvolvido para auxiliar na administração de uma pizzaria. A proposta é oferecer uma interface simples e organizada para controlar informações de clientes, fornecedores e movimentações financeiras do estabelecimento.

## 🚀 Funcionalidades

- **Login:** Tela de autenticação para acesso ao sistema.
- **Cadastro de Clientes:** Registro de informações pessoais, telefones e endereço dos clientes.
- **Cadastro de Fornecedores:** Armazenamento de dados de empresas fornecedoras, incluindo nome, telefone, CNPJ e endereço.
- **Controle de Caixa:** Registro de entradas e saídas financeiras.
- **Saldo:** Visualização do saldo, débitos e lucro do estabelecimento.
- **Observações:** Campo para adicionar informações complementares aos registros.

## 💰 Controle Financeiro

O sistema apresenta duas categorias de movimentação:

- 🟢 **Entrada:** Recebimentos de clientes.
- 🔴 **Saída:** Pagamentos de fornecedores.

Também permite registrar descrição, data e observações de cada movimentação.

## 🖥️ Interface do Sistema

O projeto conta com telas desenvolvidas para facilitar a navegação e o gerenciamento das informações:

1. Tela de Login.
2. Tela de Cadastro de Fornecedores.
3. Tela de Cadastro de Clientes.
4. Tela de Controle de Caixa.

## 🎯 Objetivo

Desenvolver uma solução que facilite o controle administrativo e financeiro de uma pizzaria, centralizando informações importantes e tornando a organização do estabelecimento mais prática e eficiente.
