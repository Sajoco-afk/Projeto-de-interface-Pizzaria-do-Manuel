# Projeto-de-interface-Pizzaria-do-Manuel
O projeto Pizzaria do Manoel consiste no desenvolvimento de um sistema de gerenciamento para uma pizzaria, com telas de login, cadastro de clientes e fornecedores e controle de caixa. O sistema permite organizar informações, registrar entradas e saídas financeiras, acompanhar saldo, débitos e lucros, facilitando a administração do negócio.
