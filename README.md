# 🍕 Pizzaria do Manoel

## 📌 Sobre o projeto

O **Pizzaria do Manoel** é um projeto de prototipação de um sistema de gerenciamento para uma pizzaria, desenvolvido utilizando o **Figma**. O objetivo é criar uma interface visual simples e organizada para facilitar a administração de clientes, fornecedores e movimentações financeiras.

## 🚀 Funcionalidades planejadas

- **Login:** Tela de autenticação para acesso ao sistema.
- **Cadastro de Clientes:** Registro de informações pessoais, telefones e endereço.
- **Cadastro de Fornecedores:** Armazenamento de dados de empresas fornecedoras.
- **Controle de Caixa:** Registro de entradas e saídas financeiras.
- **Saldo:** Visualização de saldo, débitos e lucro do estabelecimento.
- **Observações:** Campo para adicionar informações complementares.

## 💰 Controle Financeiro

O protótipo apresenta duas categorias de movimentação:

- 🟢 **Entrada:** Recebimentos de clientes.
- 🔴 **Saída:** Pagamentos de fornecedores.

Também prevê o registro de descrição, data e observações de cada movimentação.

## 🖥️ Ferramenta utilizada

- **Figma:** Utilizado para criação e prototipação das telas e da interface visual do sistema.

## 🎯 Objetivo

Desenvolver um protótipo de interface para um sistema de gerenciamento de pizzaria, demonstrando a organização das telas e as principais funcionalidades necessárias para facilitar o controle administrativo e financeiro do estabelecimento.
